# Project skill templates

Each subdirectory is a set of skills meant to be **copied** into a project, then committed there. This repo is not linked into the project; after the copy, the project owns the files.

Suggested destinations, depending on the harness the project cares about:

- `.agents/skills/` — Codex, Atomic, Cursor
- `.cursor/skills/` — Cursor
- `.claude/skills/` — Claude Code

No templates live here yet. Add one by creating `templates/<name>/<skill-name>/SKILL.md`.
